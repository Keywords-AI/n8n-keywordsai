# Contributor code of conduct

Contributors and maintainers of this Respan n8n integration are expected to provide a respectful, harassment-free environment for everyone, regardless of age, disability, ethnicity, gender identity or expression, experience, nationality, appearance, race, religion, sexual identity or orientation, or socioeconomic background.

## Participation

- Discuss code, evidence, and ideas respectfully. Critique the work without attacking the person.
- Welcome questions, different perspectives, and contributors with different experience levels.
- Accept constructive feedback and correct mistakes when identified.
- Respect privacy. Do not publish another person's contact information, credentials, or private messages without permission.

Harassment, threats, discriminatory remarks, personal insults, unwanted sexual attention, and deliberate disruption are unacceptable.

## Scope and moderation

These expectations apply to repository issues, pull requests, discussions, and other project spaces. They also apply when someone represents the project publicly.

Maintainers may remove content that violates these expectations, restrict participation, or exclude a participant. Responses should be proportionate and applied consistently. Maintainers are accountable to the same standards as other contributors.

## Report a concern

Contact a repository maintainer privately using contact details published on their GitHub profile. If no private route is listed, open an issue asking for a private reporting channel without including incident details or personal information.

Reports should go to this repository's maintainers. The upstream n8n team's contact from the original starter template is not this project's reporting channel. Maintainers should handle reports confidentially, investigate available information, and communicate appropriate next steps to the reporter.
